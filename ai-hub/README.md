# AI 聚合助手

一个跑在自己电脑上的「多模型聚合客户端」：左侧是各家的官方软件图标，点一下 → 填官方 API Key → 就在同一个界面里聊天，还能让多个模型同时上、再汇总成结论。

## 怎么启动

有两种用法，任选一种。

### A. 桌面版（推荐，像正常软件一样）

双击 **`启动桌面版.bat`**。

- 弹出一个**独立窗口**（不是浏览器标签，没有地址栏），标题「AI 聚合助手」
- **点右上角 × 只是收进系统托盘**，程序还在后台跑；点托盘图标 →「显示窗口」就能回来
- 任何时候按 **`Ctrl + Alt + Space`**，它会被叫到最前面（游戏、全屏也能用）
- 托盘右键菜单：显示窗口 / 重新载入页面 / 在浏览器打开 / 复制访问地址 / 重启本地服务 / 退出
- 真正退出要用托盘菜单「退出」，直接关窗口不算退出

> 首次运行会自动建一个本地运行环境并装三个小依赖（pywebview / pystray / pillow，约 15 MB），需要联网，等 1~3 分钟。之后每次启动都是秒开。
> 桌面版用的是 Edge WebView2 的**独立存档**，和你平时用 Edge 浏览器打开的那个不是同一份，所以第一次进桌面版是「空的」。迁移方法见下面「把浏览器版的数据搬到桌面版」。

### B. 浏览器版

双击 **`启动.bat`**。

它会启动一个本地服务并自动打开浏览器窗口（地址 `http://127.0.0.1:8760`）。
关闭那个黑色命令行窗口 = 退出程序。

> 直接双击 `index.html` 会因为没有本地服务而发不出请求，请务必用 `启动.bat` 或 `启动桌面版.bat`。

### 把浏览器版的数据搬到桌面版

两边各有一份独立存档（API Key、历史对话、技能都在里面）。搬一次就够：

1. 在**浏览器版**里：设置 → 历史与数据 →「备份为 JSON」，把内容复制出来（或存成文件）
2. 打开**桌面版**：设置 → 历史与数据 →「恢复」，粘贴进去 → 确认

搬完桌面版里 Key、历史对话、技能、工作流就都有了。之后两边各存各的，建议只用桌面版。

## 三步开始用

1. 点左侧任意一个模型图标（豆包 / DeepSeek / 通义千问 / Kimi / 智谱 GLM / ChatGPT）
2. 到该平台官方控制台申请 API Key，粘贴到「设置 → 模型与 API Key」
3. 点「保存」→「测试连接」，显示绿色「连接成功」就能开聊

API Key 获取地址（程序里也带链接）：

| 模型 | 控制台 |
| --- | --- |
| 豆包（火山方舟） | https://console.volcengine.com/ark |
| DeepSeek | https://platform.deepseek.com/api_keys |
| 通义千问（阿里云百炼） | https://bailian.console.aliyun.com/ |
| Kimi（月之暗面） | https://platform.moonshot.cn/console/api-keys |
| 智谱 GLM | https://bigmodel.cn/usercenter/apikeys |
| ChatGPT | https://platform.openai.com/api-keys |

豆包要注意：模型名要填火山方舟控制台里「推理接入点」的 ID（形如 `ep-2025xxxx-xxxx`），不是产品名。

## 功能

- **单模型对话**：流式输出、Markdown 渲染、复制、重新生成、随时中断
- **多模型协同**：勾选 2 个以上模型 → 同一个问题并行发给它们 → 并排对比答案 → 一键「汇总这些回答」，指定某个模型当总编，输出结论 / 共识 / 分歧 / 建议
- **工作流技能（多模型接力）**：不像普通技能只是一个提示词模板，它是**真的按顺序把任务交给不同模型干活**——第 1 步的产出自动成为第 2 步的输入，第 2 步挑完问题再交给第 3 步定稿。内置三套：写作流水线（初稿→挑问题→定稿）、方案评审（出方案→挑漏洞→收敛定案）、三遍讲透（概览→深入→出练习），每一步都能在「设置 → 工作流」里单独换模型、改提示词、增删步骤，也能自己新建
- **历史记录**：自动保存每次对话，支持搜索、重命名、删除、导出 Markdown、备份/恢复 JSON
- **技能库**：把常用系统提示存成技能（润色、小红书文案、代码审查、中英翻译、会议纪要…），对话里点亮即自动生效
- **自定义模型**：任何兼容 OpenAI `/chat/completions` 的服务都能接（OneAPI、中转站、Ollama、LM Studio）
- **附件参考**：📎 上传图片 / txt / md / csv / json / py / log / PDF / Word(docx)，也能直接 Ctrl+V 粘贴图、把文件拖进窗口；图片走多模态、文档抽出正文拼成「参考资料」随问题一起发出
- **语音输入（两套引擎）**：🎤 点一下开始说
  - **第三方识别（推荐）**：录音每 3.5 秒切成一段上传到识别接口，**边说边出字**，中文标点和口音比浏览器自带那套好很多。内置「硅基流动 SenseVoice」和「OpenAI Whisper」两个预设，也能填任意 OpenAI 兼容的 `/audio/transcriptions`（含本地 faster-whisper）。配置在「设置 → 语音与工具」
  - **浏览器自带**：免配置，Edge / Chrome 可用，效果一般
- **朗读**：每条回答下面有「朗读」，走 edge-tts 在本机合成（8 个中文音色、可调语速），点一下念、再点一下停
- **导出文件（带版式模板）**：每条 AI 回答下面有「导出 Word / 导出 PPT / 导出 Excel」，本地服务真的把 Markdown 转成 .docx / .pptx / .xlsx：
  - Word：微软雅黑 + 1.45 行距、标题分色、表格蓝底表头 + 斑马纹、页脚带页码
  - PPT：封面 / 自动目录 / 章节过渡页 / 正文分页 / 真表格 / 代码块底色 / 页脚页码，深色与浅色两套配色（设置里选）
  - Excel：表头蓝底、斑马纹、数值列右对齐带千分位、自动列宽、冻结首行、自动筛选
- **工具型技能（真去干活，不只是提示词）**：输入框上方点「🔧 工具」开启后，模型可以
  - 联网搜索（博查 API，或免 Key 抓必应 / 360 结果）
  - 打开网页读正文、做精确计算
  - 读写程序目录下的 `文件区/`（看完的结果可以让它直接存成 md 文件）
  调用过程在回答上方逐条显示（🔍 联网搜索 / 🌐 读取网页 / 🧮 精确计算…），最多连跑 4 轮
- **长文档检索**：附件正文超过 3600 字时自动切成 700 字一段，按你的提问挑最相关的 4 段送进去，并在消息里标注「共 N 段，挑了最相关的 M 段」，长手册也不再撑爆上下文
- **生图多轮改图**：出图后点「基于这张改」把这张设为底稿，下一次描述会走 `/images/edits` 在原图基础上改（OpenAI gpt-image-1 这类支持改图的模型可用）；输入框上方还有 1:1 / 3:4 / 4:3 / 9:16 / 16:9 五档尺寸
- **生图**：顶部第四个模式「生图」，填一句描述直接出图，支持智谱 cogview-4、OpenAI gpt-image-1、通义万相、豆包生图（各自 Key 各自计费），出图后可保存/放大
- **生成参数**：设置 → 生成参数，可调温度、最大长度、上下文轮数（省 token），并看累计调用次数 / 字符量 / 生图数
- **自动裁剪上下文**：聊得很长时只把最近若干轮发给模型，避免超长报错和浪费 token

## 工作流怎么用

1. 顶部切到「工作流」模式
2. 输入框上方那条选一个工作流（写作流水线 / 方案评审 / 三遍讲透），想给它喂资料就填进「参考资料」，会附给每一步
3. 输入任务 → 回车，卡片里会按 1 / 2 / 3 依次显示每一步是谁在写、正在运行还是已完成，最后一步标「成品」
4. 某一步指定的模型没填 Key，程序会自动用你已配置的模型顶上，并在该步骤右上角标注「已用 XX 代替」

想改流水线：设置 → 工作流，可改名称、每一步的步骤名 / 模型 / 系统提示词，也能增删步骤或删掉整条、新建一条。

## 附件与语音的小提示

- 一次最多 6 张图片，单张会先压到 1280px 再上传（省流量）；文本类文件单次最多取 6 万字
- PDF / Word 是**抽正文**，扫描件（纯图片）抽不出字，会提示你改用文字粘贴
- 语音识别建议用第三方：硅基流动 SenseVoice 按音频秒数计费，很便宜；Key 在 https://cloud.siliconflow.cn/account/ak 申请
- 录音需要浏览器授权麦克风；网页必须用 http://127.0.0.1 打开（`启动.bat` 启动的地址），用 `file://` 直接开页面拿不到麦克风
- 图片参考能不能用，取决于所选模型是否支持多模态：DeepSeek 文本模型、Kimi 部分模型不认图，会返回报错

## 联网搜索与语音的 Key（都可留空跳过）

| 能力 | 要不要 Key | 说明 |
| --- | --- | --- |
| 联网搜索 | 可留空 | 留空走免 Key 抓必应中文结果（解析网页，偶尔不够精准）；填博查 Key 更稳 |
| 网页正文 | 不用 | 本地服务直接抓页面转纯文本（PDF 不支持） |
| 语音识别 | 要 | 硅基流动或 OpenAI 的 Key，填在「设置 → 语音与工具」 |
| 朗读 | 不用 | edge-tts 走微软免费接口，首次点朗读会自动 `pip install edge-tts` |

## 导出文件的依赖

导出 Word / PPT / Excel 需要 `python-docx`、`python-pptx`、`openpyxl` 三个库。
第一次点导出时本地服务会自动 `pip install` 一次（静默执行，不弹窗）；装完就能一直用。
如果公司网络禁 pip，可先手动装：`pip install python-docx python-pptx openpyxl`。

## 数据在哪

- API Key 与全部对话都存在**本机浏览器 localStorage**，不经过任何服务器
- 服务端只做一件事：把你的请求原样转发给模型厂商（因为浏览器直连会被跨域拦掉）
- 想换电脑：设置 → 历史与数据 → 备份为 JSON

## 常见报错

| 提示 | 原因 |
| --- | --- |
| 401 | Key 错误 / 未开通权限 |
| 404 | 接口地址或模型名不对（豆包要填 ep-xxxx） |
| 400 model not found | 模型名请改成控制台显示的完整名称 |
| 连不上本地服务 | 没用 `启动.bat` 启动，或端口被占用 |

## 桌面版说明（技术细节）

- 用的是 **Edge WebView2** 内核（Windows 10/11 自带，无需另装浏览器），所以页面渲染、语音、剪贴板都跟 Edge 里一致
- `desktop.py` 干三件事：后台线程起本地服务 → 开一个 1300×860 的独立窗口 → 挂系统托盘和全局热键
- 全局热键走 Windows 原生 `RegisterHotKey`，**不装键盘钩子**，不会触发杀毒软件的键盘记录告警；热键被别的软件占用时会安静跳过（功能仍可用，只是没有快捷键）
- 关窗口不退出：`closing` 事件被拦截并改为隐藏，所以托盘常驻、热键随时能唤出
- 桌面版的存档在 `.webview\`（WebView2 的独立用户数据目录）；浏览器版的存档在 Edge 自己的 profile 里，两者互不影响
- `desktop.py --smoke N` 可以自检：起窗口 N 秒后自动退出并打印 `SMOKE_OK port=…`，用来排查启动问题

## 文件结构

```
AI聚合助手/
├── 启动桌面版.bat  ← 双击这个（桌面壳，推荐）
├── 启动.bat        ← 浏览器版
├── desktop.py      ← 桌面壳（独立窗口 + 托盘 + 全局热键）
├── server.py       ← 本地服务（转发请求 + 托管页面 + 导出文件 + 搜索/抓网页/计算/ASR/TTS，纯标准库实现）
├── index.html      ← 界面的全部代码
├── 文件区/         ← 工具读写文件的沙盒目录（出不了这里）
├── .venv/          ← 首次运行自动创建，装 pywebview/pystray/pillow
├── .webview/       ← 桌面版的浏览器存档（Key、历史对话）
└── assets/icons/   ← 官方软件图标
```

## 桌面快捷方式

桌面上的「AI 聚合助手」快捷方式已指向 启动.bat，图标用的是自定义的 AI 紫色方块图标（`assets/app-icon.ico`，含 16/24/32/48/64/128/256 多尺寸）。
启动后浏览器窗口会自动打开，控制台窗口是**最小化**的：想退出程序，关掉任务栏里那个黑色的命令行窗口即可。
