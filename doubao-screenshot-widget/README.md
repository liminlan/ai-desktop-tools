# 豆包截图挂件 · 使用说明

一个圆形小挂件，点一下就能框选屏幕上的任何地方，自动发给免费视觉模型，答案从挂件上方的小卡片弹出来。
不用切窗口、不用复制粘贴、不占任务栏，像个小挂件贴在桌面上。

---

## 一、第一次使用（3 步，约 2 分钟）

### 1. 拿一个免费的 API Key

1. 打开 https://open.bigmodel.cn/usercenter/apikeys （智谱开放平台，国内直连，不用梯子）
2. 注册 / 登录（手机号即可）
3. 在「API Keys」页面点「创建新的 API Key」，复制那一串字符

> 我们用的模型 `GLM-4.6V-Flash` 是智谱官方标注 **输入、输出全免费** 的视觉模型，
> 个人每天截图问几十次完全在免费范围内，不需要充钱。
> 参考：https://docs.bigmodel.cn/cn/guide/start/pricing

### 2. 打开挂件

双击 `豆包截图挂件.exe`（推荐），或在装有 Python 的电脑上双击 `启动挂件.bat`。

屏幕边缘会出现一个紫色的圆球。**平时它只露一半**，贴在屏幕左边或右边（像 4399 游戏盒那种边缘小窗），
鼠标靠近才整个滑出来，鼠标移开 1 秒左右又自动缩回去，不挡桌面。

### 3. 填 Key

右键圆球 →「设置」→ 粘贴 API Key → 点「测试」，看到「连接成功」就点「保存」。
模型保持默认的 `GLM-4.6V-Flash（官方免费，推荐）` 即可。

## 二、日常怎么用

| 操作 | 效果 |
| --- | --- |
| **单击圆球** | 屏幕变暗，用鼠标拖出一个框 → 松手，自动截图并提问 |
| **框选时按 Enter** | 直接截整个屏幕 |
| **框选时按 Esc / 右键** | 取消这次截图 |
| **Ctrl+Alt+Q** | 不用点圆球，直接开始框选（老板键，随时按） |
| **卡片底部输入框** | 打字继续追问，AI 记得这张图（比如先问「这是啥」，再问「第 3 步怎么点」） |
| **按住圆球拖动** | 随便挪位置，松手就自动吸附到最近的那一侧屏幕边缘，并记住纵向位置 |
| **鼠标移到圆球上** | 收起状态（半圆）自动展开成整圆 |
| **鼠标离开圆球** | 约 1 秒后自动缩回半圆贴边，不占桌面 |
| **卡片顶部缩略图** | 显示你这次截的是哪块画面，**点它直接另存** |
| **「存图」按钮** | 把原始截图另存为 PNG 或 JPG（不压缩，原分辨率） |
| **「麦」按钮** | 唤起 Windows 自带听写，你说话就变成输入框里的字，说完再点一次停止 |
| **右键圆球** | 截图 / 重看上次截图 / 设置 / 使用说明 / 退出 |

回答会以纯文本显示，卡片高度自适应，内容太长可以用鼠标滚轮翻。

## 三、几个实用场景

- **看不懂的报错**：截报错框 → 直接问怎么修
- **GitHub / 陌生网站**：截你不认识的界面 → 问「这个按钮是干嘛的」「我要 fork 该点哪」
- **英文界面**：把提问方式改成「把图中英文翻译成中文，并说明每个按钮的作用」
- **作业截图**：截题目 → 要思路
- **软件设置**：截设置面板 → 问「我要关掉开机自启该点哪个」

改「提问方式」在设置里，想让它固定做什么就写进去，比如：
> 我在学 Java，图里是代码就指出错在哪一行、为什么错、怎么改。

## 四、常见问题

**Q：提示「API Key 无效」怎么办？**
去 open.bigmodel.cn 重新复制一次 Key，注意不要带空格，也不要复制到别的项。

**Q：提示「请求太频繁」？**
免费模型有并发限制，等几秒再点一次即可。

**Q：圆球只露一半，看着像被切掉了？**
这是设计如此——平时缩成半圆贴在屏幕边缘，鼠标靠近才展开成整圆。想换边就把圆球直接拖到另一侧，松手自动吸附。

**Q：截图里会带上圆球或答案卡片吗？**
不会。点下截图的那一刻，圆球和答案卡片都会先隐藏，等截完再回来，所以截出来的画面是干净的。

**Q：截完的图我想留着，怎么办？**
两种方式：点卡片底部的「存图」按钮，或直接点卡片顶部的缩略图，都会弹出另存为对话框，选 PNG 就是原图无损保存。

**Q：点「麦」没反应 / 不出字？**
这个功能是借 Windows 自带听写（Win+H），需要两个条件：① 电脑有麦克风且没被静音；② 系统设置里「隐私 → 语音 → 在线语音识别」是开着的。第一次用可能要先允许一次。实在不行就用打字，或者你输入法自带的语音输入。

**Q：截图框选的位置和我拖的框对不上？**
一般是多屏缩放比例不同导致的。把挂件拖到主屏上用，或告诉我们你的显示器缩放比例（如 125%），可以调适配。

**Q：占多少资源？**
exe 约 15MB，常驻内存约 40–70MB，空闲时几乎不占 CPU。不写注册表、不开机自启（想要开机自启可自建快捷方式放到 `shell:startup`）。

**Q：会不会偷偷上传我的屏幕？**
只在**你框选并松手**的那一刻，把那一小块图发给智谱的接口用于识别。你不点，它什么都不传。截图只在内存里处理，不落盘。

**Q：免费会不会哪天没了？**
免费政策由智谱决定，可能调整。真变了，就在设置里换模型，或改用其他家的免费额度接口（代码里 `MODELS` 列表加一行即可）。

## 五、文件说明

| 文件 | 作用 |
| --- | --- |
| `豆包截图挂件.exe` | 主程序，双击就能跑，不需要 Python |
| `启动挂件.bat` | 用源码启动的备用方式（需要 Python + Pillow） |
| `doubao_orb.py` | 完整的源码，想改颜色/尺寸/模型都在这里 |
| `config.json` | 你的设置（API Key、模型、提问方式、圆球位置），首次保存后生成 |
| `icon.ico` | 图标 |

想改外观：`orb_images()` 里的 `center` / `edge` 两个颜色值控制圆球渐变色，`Bubble.width` 控制卡片宽度。

自检命令（排查问题时用）：
```
python doubao_orb.py --selftest        # 检查抓屏、编码、GUI 是否正常
python doubao_orb.py --preview         # 生成两张预览图：贴边收起态 + 展开带卡片
python doubao_orb.py --capture-test    # 真实走一遍截图流程，把抓到的画面存成 debug_capture.png
```
